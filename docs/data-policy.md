# 外部データ利用方針

## 目的

本教材では、言語コーパス、辞書、研究データ、観測データなど、第三者が作成・公開したデータを教材の題材や検証に利用することがある。

この文書は、その際に **公開されていること、解析に使えること、教材内で引用できること、リポジトリへ再配布できることを区別して扱う**ための一般方針を定める。

本方針はプロジェクト上の運用基準であり、個別案件についての法律相談や法的判断そのものではない。明示されたライセンス、利用規約、権利者の許諾、適用法令がある場合は、それらを優先する。

## 1. 基本原則

外部データについて、次の4つを別々に判断する。

1. **取得・閲覧できるか**
2. **解析に利用できるか**
3. **教材本文で一部を引用・例示できるか**
4. **元データまたはそれに近いデータを tinyxfmr から再配布できるか**

特に、Web上で無償公開されていることだけを理由に、再配布可能とは判断しない。

## 2. 明示的なライセンスがある場合

データにライセンスが明示されている場合は、その条件に従う。

最低限、次を確認する。

- 再配布の可否
- 改変・派生物作成の可否
- 商用利用の可否
- 帰属表示の方法
- 同一ライセンス条件の有無
- データベース権その他、データ固有の条件
- ライセンスとは別に利用規約が存在しないか

リポジトリへ収録する場合は、出典とライセンス情報をデータの近くに残す。

## 3. ライセンスが明示されていない場合

研究者が研究再現用データを公開していても、個別データファイルに再配布ライセンスが明示されていないことは珍しくない。

この場合、本プロジェクトでは次を既定方針とする。

### 3.1 解析には利用する

入手可能な公開データを、教材設計の検討、統計解析、モデル評価、再現実験の入力として利用することは検討対象とする。

ただし、公開元の利用規約等が解析を制限している場合はそれに従う。

### 3.2 元データは原則として再配布しない

ライセンスまたは権利者の許諾を確認できるまで、元データ一式を `data/` 等へコピーして公開しない。

次のような行為も、実質的に元データの代替物になる場合は同様に慎重に扱う。

- 全件を別形式へ変換しただけのファイル
- 表記を正規化しただけの全件データ
- 一部の列を削除しただけで元データの大半を復元できる派生物
- 圧縮、符号化、tokenize など、内容をほぼ保持した変換結果

「派生データ」と呼べることだけを理由に再配布可能とは判断しない。

### 3.3 解析結果・集計統計は原則として収録可能

元データを代替せず、個々のレコードを実質的に復元できない集計結果については、出典を明示したうえで教材やリポジトリへ収録することを基本とする。

例:

- 件数
- 頻度表
- 遷移回数表
- 確率分布
- 平均・分散
- accuracy
- cross entropy / perplexity
- 学習曲線
- 比較図表

ただし、非常に小さなデータセットなど、集計値から元データをほぼ復元できる場合は個別に再検討する。

### 3.4 引用・例示は必要最小限にする

教材本文で元データの実例を示す必要がある場合は、説明に必要な範囲の少数例に限定し、出典を明示する。

引用例は、元データそのものを教材の主要コンテンツとして代替提供するためではなく、分析対象や変換方法を説明するために用いる。

多数の例が教材に必要になった場合は、「引用を増やす」のではなく、再配布許諾を得る、明示的に再利用可能な別データを探す、あるいは人工データと明記して作成することを優先する。

## 4. 教材でデータを使うときの優先順位

教材データは、可能なら次の順に選ぶ。

1. 明示的なオープンライセンスで、教材への再配布が可能なデータ
2. 権利者から教材への収録許諾を得たデータ
3. 元データは外部参照とし、tinyxfmr には解析コードと集計結果だけを置くデータ
4. 出典付きの必要最小限の引用だけを使うデータ
5. 教材のために作成した人工データ

人工データを使う場合は、実測データであるかのように見せない。

## 5. 静的教材での扱い

tinyxfmr は静的配信を前提としているため、外部データを実行時に必ず取得する構成は核心教材では避ける。

元データを同梱できない場合は、次のいずれかを用いる。

- リポジトリに収録できる集計済み統計を使う
- 小さな引用例だけを教材に含める
- 開発・検証用に、利用者が公開元から取得したデータを解析するスクリプトを用意する
- 再配布許諾を取得してから教材用データを同梱する

外部URLからの取得を実装する場合も、公開元に過度な負荷をかけないこと、取得条件や利用規約に反しないこと、教材の核心が外部サービス停止で壊れないことを確認する。

## 6. 出典と来歴を残す

外部データを利用した場合は、再現性のため少なくとも次を文書化する。

- データセット名
- 作成者または公開主体
- 原論文または一次資料
- DOI または恒久的な参照先（ある場合）
- 入手先URL
- 利用した版・日付
- ライセンスまたは権利状態
- 元データから教材用表現までの変換手順
- 除外・正規化・統合などの処理
- 教材内で実データと人工データを混ぜた場合は、その境界

数値結果だけを残して、どのデータからどの処理で生成したか分からなくなることを避ける。

## 7. 許諾を求める基準

次のいずれかに該当する場合は、可能なら権利者・公開者に再配布許諾を求める。

- 元データを静的教材へ同梱することが教育上重要
- 読者自身に元データ全体を数えたり変換したりする体験をさせたい
- オフラインでも同じ教材体験を成立させたい
- 引用では足りない量の実例が必要
- 派生データが元データの実質的な代替物になり得る

許諾を得た場合は、許諾範囲と表示条件をリポジトリ内に記録する。

## 8. レビュー時のチェックリスト

外部データを追加・変更するPRでは、最低限次を確認する。

- [ ] 出典が明記されている
- [ ] 明示的なライセンスまたは利用規約を確認した
- [ ] 「公開されている」ことだけを再配布根拠にしていない
- [ ] 元データ、引用、派生統計のどれを収録しているか区別されている
- [ ] 派生物から元データを実質的に復元できないか確認した
- [ ] 引用は教材上必要な範囲に限定されている
- [ ] 変換・除外・正規化手順が記録されている
- [ ] 実測データと人工データの境界が明確である
- [ ] ライセンス不明の元データをリポジトリへ vendor していない

## 9. Shona learning data への適用

第一課の候補として検討している Hayes & Wilson (2008) の Shona learning data については、現時点で次のように扱う。

### 出典

- Bruce Hayes & Colin Wilson, "A Maximum Entropy Model of Phonotactics and Phonotactic Learning", *Linguistic Inquiry* 39(3), 379–440, 2008.
- DOI: <https://doi.org/10.1162/ling.2008.39.3.379>
- 研究ページ: <https://brucehayes.org/Phonotactics/>
- 公開 learning data: <https://brucehayes.org/Phonotactics/files/ShonaLearningData.txt>
- 論文では Hannan (1959) の Shona dictionary のオンライン版をもとに 4,399 動詞を利用している。

### 現時点の権利状態の扱い

研究ページから learning data を自由に取得できるが、**当該データファイル自体について tinyxfmr からの再配布を明示的に許可するライセンスは、現時点で確認できていない**。

研究ページ上のソフトウェア等に別途ライセンス表示があっても、それを個別データファイルへ自動的に適用しない。

### tinyxfmr で行ってよいこと

現時点では次を行う。

- 公開元から取得したデータを開発・研究目的で解析する
- 母音 `a e i o u` のみを抽出する解析コードを書く
- unigram / 1次Markov / 2次Markovを比較する
- 5×5の母音遷移回数表・確率表を生成して収録する
- cross entropy 等の評価結果を収録する
- 母音調和の性質を説明するため、必要最小限の実例を出典付きで示す
- 元データの取得方法と解析手順を再現可能に文書化する

### 現時点では行わないこと

再配布許諾または適用可能なライセンスを確認するまで、次は行わない。

- `ShonaLearningData.txt` 全体をリポジトリへコピーする
- 4,399語をほぼそのまま別形式で収録する
- 4,399語すべてから子音を削除した母音列全集を収録する
- 元データを実質的に再構成できる形の派生コーパスを公開する

### 教材実装上の当面の方針

第一課の候補評価では、まず外部データを解析して次を計測する。

1. 5母音の頻度
2. 5×5遷移回数・遷移確率
3. unigram baseline
4. 1次Markovの予測性能
5. 2次Markovの予測性能
6. 語末 `a` 等の形態論的偏りが結果へ与える影響

教材として採用する場合、集計済み5×5表だけで十分な学習体験になるかを確認する。

読者自身が4,399語から母音を抽出して数える過程を教材の中心に置きたい場合は、元データの教材同梱について Hayes / Wilson ら公開者へ許諾を求めることを第一案とする。

許諾が得られるまでは、元データの再配布を前提としない教材設計にする。
