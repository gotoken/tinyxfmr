# 予測課題のデータ候補

Transformer に入る前の最初の課題では、「次に何が起こるかを確率として予測する」こと自体を、できるだけ小さな記号集合で理解できるデータを使いたい。

現時点の優先順位は次の通り。

1. **第一候補: Shona（ショナ語）動詞の母音列**
2. 比較候補: 睡眠ステージ（Sleep-EDF Expanded）

いずれも採用決定ではなく、教材実装とストーリーを比較するための候補として記録する。

---

## 第一候補: Shona 動詞の母音列

### 概要

Shona は Zimbabwe などで話される Bantu 諸語の一つで、母音は次の5種類である。

```text
a e i o u
```

Shona の動詞には強い母音調和（vowel harmony）の制約があり、子音を無視して母音だけを取り出すと、後続母音の分布が直前の母音に強く依存する。

例えば元の語形を音素列として

```text
b a n d i r a
```

と表したとき、教材では子音を隠して

```text
a i a
```

だけを観測する。

これにより、実在言語から得られたデータを使いながら、モデルの語彙をちょうど5種類にできる。

### 先行研究と公開語彙データ

Hayes & Wilson (2008) は、Shona の母音調和を phonotactics（音素配列制約）の学習問題として扱っている。

論文では Hannan (1959) の Shona dictionary のオンライン版（CBOLD project）から **4,399個の Shona 動詞**を分析し、5母音からなる全25種類の二母音列について訓練データ中の出現回数を集計している。

- Bruce Hayes & Colin Wilson, "A Maximum Entropy Model of Phonotactics and Phonotactic Learning", *Linguistic Inquiry* 39(3), 379–440, 2008.
- DOI: <https://doi.org/10.1162/ling.2008.39.3.379>
- 著者による研究ページ: <https://brucehayes.org/Phonotactics/>
- 著者が公開している Shona learning data: <https://brucehayes.org/Phonotactics/files/ShonaLearningData.txt>

研究ページでは、論文で使用した Shona vowel harmony の simulation files として learning data、feature chart、projection file、trigram limitation file、testing results が公開されている。

learning data は例えば次のような、分かち書きされた音素列である。

```text
b a n d i r a
b a n d u k a
b e r e r e dz a
...
```

したがって `a/e/i/o/u` だけを抽出する処理は非常に単純で、教材用データの生成過程も読者へ説明できる。

### 低次の依存が期待できる理由

Hayes & Wilson は Shona を、動詞語幹では母音調和の例外が比較的少なく phonotactic principle が明瞭な言語として選んでいる。

論文で整理されている主要な分布制約は、母音だけを並べた tier 上では非常に局所的である。概略として、

- `a` は自由に分布する
- 非語頭の `e` は先行母音が `e` または `o` の場合に現れる
- 非語頭の `o` は原則として先行母音が `o` の場合に現れる
- `i` は先行母音が `e` または `o` の場合に強く抑制される
- `u` は先行母音が `o` の場合に強く抑制される

という形を取る。

Hayes & Wilson が示す4,399動詞の二母音列集計でも、これらの制約に強く反する組み合わせは非常に少ない。

さらに同論文では、通常の音素列上では子音を隔てた非局所的関係である母音調和を、**vowel projection** を導入して母音だけの tier に写すことで局所的な制約として学習している。学習された主要制約も、vowel tier 上では隣接する母音対に対する制約として表現される。

このため、教材では

```text
X_t ∈ {a, e, i, o, u}
```

として、まず

```text
P(X_(t+1))
```

を数え、次に

```text
P(X_(t+1) | X_t)
```

を数える課題が自然に成立する可能性が高い。

ただし、**Hayes & Wilson が「Shona の母音列は1次Markov過程で十分に予測できる」と評価したわけではない**。先行研究から直接言えるのは、母音 tier 上の局所的な二項制約が非常に強いことである。

したがって「1次Markovモデルがどの程度よく当たるか」は tinyxfmr 側で実データを使って測定し、教材採用の判断材料にする。

### 教材上の利点

#### 1. 記号が自然に5種類だけになる

人工的に `A B C D E` を作るのではなく、実在言語の母音体系そのものが5種類である。

```text
a e i o u
```

最初の確率分布も5個だけで済む。

```text
P(a), P(e), P(i), P(o), P(u)
```

#### 2. 「数えただけで言語の規則が見える」という導入ができる

読者には Shona の母音調和規則を先に教えない。

まず実在する動詞を大量に観察し、母音を抽出して遷移回数を数える。すると、5×5の表に偏りやほぼ空のセルが現れる。

その後で、

> 私たちは Shona の文法をモデルに教えていない。実際に使われている語を数えただけで、言語にある規則が確率の偏りとして見えてきた。

という形で「データから規則を学ぶ」ことを導入できる。

これは最終的な言語モデルとの概念的な距離が、睡眠ステージより小さい。

#### 3. 第1回から第2回への接続が自然

第1回では、母音全体の頻度だけから次を予測する。

```text
P(next vowel)
```

このモデルでは現在の母音による違いを表せない。

第2回で現在母音を条件に加える。

```text
P(next vowel | current vowel)
```

すると5×5の表になり、Shona の母音調和による強い偏りが現れることが期待できる。

これは「現在のモデルの失敗を観察してから次の仕組みを導入する」という tinyxfmr の教材原則と特に相性がよい。

#### 4. 「何を観測するか」という問題も後で扱える

通常の音素列では母音同士は子音を隔てている。

```text
b a n d i r a
```

しかし母音だけを投影すると、

```text
a i a
```

となり、母音間の依存が局所的に見える。

これは Attention を直接説明するものではないが、

> 系列に含まれるすべての情報が、今の予測に同じように重要とは限らない

という後の議論への伏線にできる。

### 注意点・未決事項

#### 辞書の動詞は独立した系列として扱う

異なる単語の末尾と語頭を接続すると、実際には存在しない母音遷移を生成する。

したがって各動詞は別系列として扱い、単語境界を越えた next-vowel prediction は行わない。

開始・終了記号をモデルの語彙に含めると5種類という利点が薄れるため、第1段階では「語中で次の母音が存在する位置だけを訓練例とする」方法を第一に検討する。

#### 動詞末尾の `a` が強い偏りを作る

Hayes & Wilson は、辞書中の動詞が suffix `-a` で終わるため、learning data の最終母音は常に `a` であることを明記している。

これは自然な形態論的事実ではあるが、母音調和とは別の強い予測手掛かりになる。

教材用データを作る際は、

- 最終 `a` を含める
- 最終位置だけ除外する
- 語幹・接辞境界を利用できるなら別に扱う

のどれが最も教材目的に合うかを実測して決める。

#### 公開されていることと再配布可能であることを区別する

Hayes & Wilson の研究ページでは Shona learning data が誰でも取得できる形で公開されており、論文・研究データとして出典を明示して参照できる。

一方、研究ページで明記されている GPL はソフトウェアについての記述であり、**learning data の再配布ライセンスまで明示しているとは現時点では確認できていない**。

したがって、元 learning data を tinyxfmr リポジトリへそのまま収録することは、ライセンスまたは許諾を確認するまで保留する。

教材では当面、

- 論文と公開 learning data を引用する
- 解析スクリプトが原サイトから取得する方式を検討する
- 小規模な引用例を掲載する場合も出典を明示する

という方針とする。

### 採用判断のために次に確認すること

1. 公開 Shona learning data を取得し、各語から `a/e/i/o/u` だけを抽出する。
2. 母音頻度と5×5の二母音遷移表を再現し、Hayes & Wilson の Table 6 と照合する。
3. 単語単位で train/test を分割する。
4. unigram と1次Markov（bigram）の test cross entropy / negative log likelihood / accuracy を比較する。
5. 2次Markov（trigram）まで増やした場合に改善がどの程度残るか測る。
6. 最終 `a` を含む場合と除く場合を比較する。
7. unseen transition の扱いとして smoothing が教材のどの段階で必要になるか確認する。
8. 第1〜数回で同じデータを使い続けたとき、各回で導入したい「現在のモデルの限界」が実際に観察できるか確認する。
9. learning data の再配布条件を確認し、必要なら著者への確認または原サイト取得方式を採用する。

この実測で unigram から1次Markovへの改善が明瞭で、2次以上での改善が小さければ、第1〜2回の題材として非常に強い候補になる。

## 比較候補: 睡眠ステージの時系列

人の睡眠は、終夜ポリソムノグラフィ（PSG）の記録を一定時間ごとに判定し、睡眠段階の系列として表せる。

教材では次の5状態にそろえて扱える。

- `W` — 覚醒
- `N1` — NREM stage 1
- `N2` — NREM stage 2
- `N3` — 深いNREM睡眠
- `R` — REM睡眠

したがって、観測データは概念的に次のような5種類だけの記号列になる。

```text
W W W N1 N1 N2 N2 N2 N3 N3 N2 N2 R R ...
```

予測課題は、ここまでの観測を入力として「次の区間が5状態のどれになるか」を予測するものとする。

これは言語モデルの next-token prediction と同型でありながら、最初から数十〜数百種類の文字や単語を導入せずに済む。

## 公開観測データ: Sleep-EDF Database Expanded

PhysioNet の [Sleep-EDF Database Expanded](https://physionet.org/content/sleep-edfx/1.0.0/) は、197件の終夜PSG記録と、それに対応する専門技師による睡眠段階の手動判定（hypnogram）を公開している。

- Dataset: Sleep-EDF Database Expanded v1.0.0
- DOI: <https://doi.org/10.13026/C2X676>
- License: Open Data Commons Attribution License v1.0 (ODC-By 1.0)
- 元の判定基準: Rechtschaffen & Kales (R&K)

Sleep-EDF の hypnogram のラベルは次の8種類である。

```text
W, 1, 2, 3, 4, R, M, ?
```

教材用の5状態への変換候補は次の通り。

```text
W    -> W
1    -> N1
2    -> N2
3, 4 -> N3
R    -> R
```

AASM の睡眠段階分類では、旧R&Kの stage 3 と stage 4 が N3 に統合されている。このため `3, 4 -> N3` は一般的な5段階化と整合する。

`M`（Movement time）と `?`（not scored）は5状態の正解ラベルとして使わない。単純に削除して前後を連結すると、実際には観測されていない遷移を作るので、教材データを作る際はその位置で系列を分断することを基本とする。

## この候補の教材上の利点

### 1. 記号の種類が本当に少ない

人工的に `A B C D E` と作った課題ではなく、現実の観測結果を5種類の記号として扱える。

このため、第1回で必要な表やグラフをすべて小さく保てる。

例えば次状態の確率は常に5個だけである。

```text
P(W), P(N1), P(N2), P(N3), P(R)
```

### 2. 正解データの意味が明瞭

各時点の正解は、実際に次の区間に専門技師が付けた睡眠段階である。

入力系列を1つずらせば、next-token prediction と同じ教師データを作れる。

```text
入力: W  N1 N2 N2 N3 N3 N2
正解: N1 N2 N2 N3 N3 N2 R
```

ただし、1件の観測で `R` が正解だったことは「Rだけが可能」という意味ではない。多数の観測から条件付きの出現割合を学ぶことで、予測を確率分布として考える導入に使える。

### 3. Bigram / マルコフ連鎖へ自然につながる

最初は状態の出現頻度だけを数え、その後

```text
P(next | current)
```

を数えれば、5×5の遷移表になる。

これは第1回の頻度予測から第2回の条件付き確率・Bigramへ進む教材構成と対応がよい。

睡眠ステージ列そのものも、研究上マルコフ連鎖や半マルコフ過程などでモデル化されてきた対象である。

### 4. 後で「文脈が必要」という問題へ発展できる

現在のステージだけを見た1次マルコフモデルは分かりやすいが、本物の睡眠はそれだけでは完全には表せない。

例えば同じ `N2` でも、

```text
W -> N1 -> N2
```

と来た場合と、

```text
N3 -> N2
```

と来た場合では、系列の意味が異なる可能性がある。

この差を教材で実測できれば、「現在の1状態だけでは足りないので過去も見たい」という第5回以降への動機として利用できる。

## 力学系としての解釈との接続

睡眠段階は、自然界に本当に5個の完全に離散した状態が存在するというより、連続的な脳状態を粗く分類した観測値とみなす余地がある。

実際、Lopour et al. (2010) は睡眠EEGの特徴を Locally Linear Embedding (LLE) で低次元空間に埋め込み、従来の睡眠段階を区別しつつ、睡眠状態が時間に沿って滑らかに変化する低次元表現を示している。

- Beth A. Lopour et al., "A continuous mapping of sleep states through association of EEG with a mesoscale cortical model", *Journal of Computational Neuroscience* 30, 471–487 (2011; online 2010).
- DOI: <https://doi.org/10.1007/s10827-010-0272-1>
- Open article: <https://pmc.ncbi.nlm.nih.gov/articles/PMC3058368/>

また、睡眠時fMRIについても、睡眠段階を含む脳活動を低次元の intrinsic manifold 上に配置する研究がある。

- "Decoding brain states on the intrinsic manifold of human brain dynamics across wakefulness and sleep"
- Open article: <https://pmc.ncbi.nlm.nih.gov/articles/PMC8270946/>

したがって、将来の教材上の見方として、背後の状態を `z_t`、観測された5段階を `x_t` として、

```text
背後:      z_t -> z_(t+1)       （連続的な状態変化）
                  |
観測:             v
            W/N1/N2/N3/R        （粗く分類された記号）
```

と捉えることもできる。

この見方では、現在のラベルだけからは背後の状態を完全には特定できず、過去の観測系列が状態推定の手掛かりになる。この性質は、後で「なぜ複数の過去を見るのか」を説明する題材になり得る。

ただし、Sleep-EDF 自体が特定の低次元力学系から生成されたことが証明されているわけではない。また、上記の埋め込み研究と Sleep-EDF は同一の観測データではない。教材で両者を結び付ける場合は、「連続状態の粗視化として解釈する研究例がある」という動機付けに留め、同一データについて実証済みであるかのようには記述しない。

## 注意点・未決事項

### 自己遷移が多い

30秒ごとの睡眠段階では同じ状態が連続することが多い。そのため単純に accuracy だけを評価すると、「次も現在と同じ」と予測するだけで高い成績になる可能性がある。

教材に採用する場合は、以下を実データで確認する。

- 各状態の頻度
- 5×5遷移行列
- 自己遷移率
- 最頻状態だけを予測する baseline
- 現在状態をそのまま予測する persistence baseline
- bigram が baseline に対してどれだけ改善するか
- 2状態以上の履歴を使うと予測がどれだけ改善するか

結果によっては、全epochをそのまま使わず、ステージ変化点を題材にする、滞在時間を別途扱う、あるいは別データ候補を選ぶ。

### 医学教材にしない

目的は睡眠医学を教えることではなく、少数状態からなる実在の時系列を使って確率予測を理解することである。

睡眠段階の生理学的詳細は、予測課題を理解するために必要な最小限だけ説明する。

### ライセンスと帰属

派生した小さな教材データをリポジトリへ収録する場合は、ODC-By 1.0 の条件を確認し、PhysioNet / Sleep-EDF への適切な帰属とライセンス情報を添える。

Sleep-EDF が指定している原論文:

B. Kemp, A. H. Zwinderman, B. Tuk, H. A. C. Kamphuisen, J. J. L. Oberyé, "Analysis of a sleep-dependent neuronal feedback loop: the slow-wave microcontinuity of the EEG", *IEEE Transactions on Biomedical Engineering*, 47(9), 1185–1194, 2000.

## Sleep-EDF を採用判断する場合に確認すること

1. Sleep-EDF の hypnogram だけを取得して5状態へ変換する小さな解析スクリプトを作る。
2. 状態頻度・遷移行列・各baselineの予測性能を測る。
3. 1状態、2状態、数状態の履歴を使ったときに予測能力がどの程度変わるかを見る。
4. 第1〜5回まで同じデータを使い続けたときに、各回の「現在のモデルの限界」が実際に観察できるか確認する。
5. Shona 母音列と比較し、最初の題材としての説明量と自然さを評価する。
