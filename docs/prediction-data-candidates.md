# 予測課題のデータ候補

Transformer に入る前の最初の課題では、「次に何が起こるかを確率として予測する」こと自体を、できるだけ小さな記号集合で理解できるデータを使いたい。

現時点では、実在する観測系列として **睡眠ステージ（Sleep-EDF Expanded）** を有力候補の一つとする。採用決定ではなく、教材実装とストーリーを比較するための候補として記録する。

## 候補: 睡眠ステージの時系列

人の睡眠は、終夜ポリソムノグラフィ（PSG）の記録を一定時間ごとに判定し、睡眠段階の系列として表せる。

教材では次の5状態にそろえて扱える。

- `W` — 覚醒
- `N1` — NREM stage 1
- `N2` — NREM stage 2
- `N3` — 深いNREM睡眠
- `R` — REM睡眠

したがって、観測データは概念的に次のような5種類だけの記号列になる。

```text
W W W N1 N1 N2 N2 N2 N3 N3 N2 N2 R R ...
```

予測課題は、ここまでの観測を入力として「次の区間が5状態のどれになるか」を予測するものとする。

これは言語モデルの next-token prediction と同型でありながら、最初から数十〜数百種類の文字や単語を導入せずに済む。

## 公開観測データ: Sleep-EDF Database Expanded

PhysioNet の [Sleep-EDF Database Expanded](https://physionet.org/content/sleep-edfx/1.0.0/) は、197件の終夜PSG記録と、それに対応する専門技師による睡眠段階の手動判定（hypnogram）を公開している。

- Dataset: Sleep-EDF Database Expanded v1.0.0
- DOI: <https://doi.org/10.13026/C2X676>
- License: Open Data Commons Attribution License v1.0 (ODC-By 1.0)
- 元の判定基準: Rechtschaffen & Kales (R&K)

Sleep-EDF の hypnogram のラベルは次の8種類である。

```text
W, 1, 2, 3, 4, R, M, ?
```

教材用の5状態への変換候補は次の通り。

```text
W    -> W
1    -> N1
2    -> N2
3, 4 -> N3
R    -> R
```

AASM の睡眠段階分類では、旧R&Kの stage 3 と stage 4 が N3 に統合されている。このため `3, 4 -> N3` は一般的な5段階化と整合する。

`M`（Movement time）と `?`（not scored）は5状態の正解ラベルとして使わない。単純に削除して前後を連結すると、実際には観測されていない遷移を作るので、教材データを作る際はその位置で系列を分断することを基本とする。

## この候補の教材上の利点

### 1. 記号の種類が本当に少ない

人工的に `A B C D E` と作った課題ではなく、現実の観測結果を5種類の記号として扱える。

このため、第1回で必要な表やグラフをすべて小さく保てる。

例えば次状態の確率は常に5個だけである。

```text
P(W), P(N1), P(N2), P(N3), P(R)
```

### 2. 正解データの意味が明瞭

各時点の正解は、実際に次の区間に専門技師が付けた睡眠段階である。

入力系列を1つずらせば、next-token prediction と同じ教師データを作れる。

```text
入力: W  N1 N2 N2 N3 N3 N2
正解: N1 N2 N2 N3 N3 N2 R
```

ただし、1件の観測で `R` が正解だったことは「Rだけが可能」という意味ではない。多数の観測から条件付きの出現割合を学ぶことで、予測を確率分布として考える導入に使える。

### 3. Bigram / マルコフ連鎖へ自然につながる

最初は状態の出現頻度だけを数え、その後

```text
P(next | current)
```

を数えれば、5×5の遷移表になる。

これは第1回の頻度予測から第2回の条件付き確率・Bigramへ進む教材構成と対応がよい。

睡眠ステージ列そのものも、研究上マルコフ連鎖や半マルコフ過程などでモデル化されてきた対象である。

### 4. 後で「文脈が必要」という問題へ発展できる

現在のステージだけを見た1次マルコフモデルは分かりやすいが、本物の睡眠はそれだけでは完全には表せない。

例えば同じ `N2` でも、

```text
W -> N1 -> N2
```

と来た場合と、

```text
N3 -> N2
```

と来た場合では、系列の意味が異なる可能性がある。

この差を教材で実測できれば、「現在の1状態だけでは足りないので過去も見たい」という第5回以降への動機として利用できる。

## 力学系としての解釈との接続

睡眠段階は、自然界に本当に5個の完全に離散した状態が存在するというより、連続的な脳状態を粗く分類した観測値とみなす余地がある。

実際、Lopour et al. (2010) は睡眠EEGの特徴を Locally Linear Embedding (LLE) で低次元空間に埋め込み、従来の睡眠段階を区別しつつ、睡眠状態が時間に沿って滑らかに変化する低次元表現を示している。

- Beth A. Lopour et al., "A continuous mapping of sleep states through association of EEG with a mesoscale cortical model", *Journal of Computational Neuroscience* 30, 471–487 (2011; online 2010).
- DOI: <https://doi.org/10.1007/s10827-010-0272-1>
- Open article: <https://pmc.ncbi.nlm.nih.gov/articles/PMC3058368/>

また、睡眠時fMRIについても、睡眠段階を含む脳活動を低次元の intrinsic manifold 上に配置する研究がある。

- "Decoding brain states on the intrinsic manifold of human brain dynamics across wakefulness and sleep"
- Open article: <https://pmc.ncbi.nlm.nih.gov/articles/PMC8270946/>

したがって、将来の教材上の見方として、背後の状態を `z_t`、観測された5段階を `x_t` として、

```text
背後:      z_t -> z_(t+1)       （連続的な状態変化）
                  |
観測:             v
            W/N1/N2/N3/R        （粗く分類された記号）
```

と捉えることもできる。

この見方では、現在のラベルだけからは背後の状態を完全には特定できず、過去の観測系列が状態推定の手掛かりになる。この性質は、後で「なぜ複数の過去を見るのか」を説明する題材になり得る。

ただし、Sleep-EDF 自体が特定の低次元力学系から生成されたことが証明されているわけではない。また、上記の埋め込み研究と Sleep-EDF は同一の観測データではない。教材で両者を結び付ける場合は、「連続状態の粗視化として解釈する研究例がある」という動機付けに留め、同一データについて実証済みであるかのようには記述しない。

## 注意点・未決事項

### 自己遷移が多い

30秒ごとの睡眠段階では同じ状態が連続することが多い。そのため単純に accuracy だけを評価すると、「次も現在と同じ」と予測するだけで高い成績になる可能性がある。

教材に採用する場合は、以下を実データで確認する。

- 各状態の頻度
- 5×5遷移行列
- 自己遷移率
- 最頻状態だけを予測する baseline
- 現在状態をそのまま予測する persistence baseline
- bigram が baseline に対してどれだけ改善するか
- 2状態以上の履歴を使うと予測がどれだけ改善するか

結果によっては、全epochをそのまま使わず、ステージ変化点を題材にする、滞在時間を別途扱う、あるいは別データ候補を選ぶ。

### 医学教材にしない

目的は睡眠医学を教えることではなく、少数状態からなる実在の時系列を使って確率予測を理解することである。

睡眠段階の生理学的詳細は、予測課題を理解するために必要な最小限だけ説明する。

### ライセンスと帰属

派生した小さな教材データをリポジトリへ収録する場合は、ODC-By 1.0 の条件を確認し、PhysioNet / Sleep-EDF への適切な帰属とライセンス情報を添える。

Sleep-EDF が指定している原論文:

B. Kemp, A. H. Zwinderman, B. Tuk, H. A. C. Kamphuisen, J. J. L. Oberyé, "Analysis of a sleep-dependent neuronal feedback loop: the slow-wave microcontinuity of the EEG", *IEEE Transactions on Biomedical Engineering*, 47(9), 1185–1194, 2000.

## 採用判断のために次に確認すること

1. Sleep-EDF の hypnogram だけを取得して5状態へ変換する小さな解析スクリプトを作る。
2. 状態頻度・遷移行列・各baselineの予測性能を測る。
3. 1状態、2状態、数状態の履歴を使ったときに予測能力がどの程度変わるかを見る。
4. 第1〜5回まで同じデータを使い続けたときに、各回の「現在のモデルの限界」が実際に観察できるか確認する。
5. しりとりなど他の候補と比較し、最初の題材としての説明量と自然さを評価する。
