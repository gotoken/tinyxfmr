# tinyxfmr

高校数学を履修した読者が、ブラウザ上の実験と丁寧な実装を追いながら、小さな言語モデルから Transformer をボトムアップに組み立て、その仕組みを正しく理解するための教材です。

## 想定

- 1回約30分、全10回程度
- 静的コンテンツとして配信
- 各回は複数の短いセクションに分かれ、各セクションに必要に応じて実験用GUIを持つ
- 読者は中学校までの数学を理解していることを前提とし、それ以降に必要な数学は本文または数学コラムで補う
- 最終課題は、ごく小さな Transformer をブラウザ上で学習させ、しりとりを生成することを想定する

## 教材の考え方

この教材では、Transformer の完成形を先に分解して説明しません。

毎回、まず現在のモデルでできることを確認し、その限界を実験で見つけます。次に、その限界を解決するための操作を導入し、必要性と利点を理解してから、数式・名称・実装を対応付けます。

たとえば softmax は「ニューラルネットでは softmax を使う」と天下りに導入するのではなく、頻度から得た確率を、学習で扱いやすい自由な score に写すために log を考え、必要になったときに exp で確率側へ戻す流れから導入します。
